# 💊 Farmácia Bem Estar

Aplicação web desenvolvida com **React + TypeScript** para gerenciamento de produtos e categorias de uma farmácia.

O projeto funciona como Front-end de uma API REST desenvolvida com **Java e Spring Boot**, oferecendo uma interface moderna, responsiva e intuitiva.

## 🚀 Funcionalidades

### 💊 Produtos
- Listagem e cadastro
- Busca e edição
- Exclusão
- Controle de preço e estoque
- Imagem por URL
- Associação com categorias

### 📂 Categorias
- Listagem e cadastro
- Edição e exclusão
- Organização dos produtos por categoria

## 🛠️ Tecnologias

### Front-end
- React 19
- TypeScript
- Vite
- Tailwind CSS
- React Router DOM
- Axios
- Phosphor Icons

### Back-end
- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven

## 🔗 Integração

A aplicação consome uma **API REST** através do Axios. A URL deve ser configurada pela variável de ambiente:

```env
VITE_API_URL=sua-url-da-api
```

## ▶️ Como executar

```bash
git clone https://github.com/phcarneiro9/Projeto_Final_Bloco_03.git
cd Projeto_Final_Bloco_03
npm install
npm run dev
```

O Vite exibirá no terminal o endereço local da aplicação.

## 🎯 Objetivo

Praticar **React, TypeScript, consumo de APIs REST, CRUD, componentização, roteamento e responsividade** em um projeto completo.
